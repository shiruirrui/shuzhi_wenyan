# 数智文言——高中古诗文学习助手

一个面向高中生的古诗文伴学 Demo，通过“情景默写 + 渐进式引导 + 错因诊断”，帮助学生在不直接看答案的情况下真正掌握古诗文。

## 功能演示

- **知识库**：收录部编版教材古诗文与高考真题，支持按朝代、体裁筛选和关键词搜索
- **启发问答**：情景默写题答错后，不直接给答案，而是分三层提示逐步引导
- **错题本**：自动记录答错的题，带错因标签、错误次数、我的错解，可一键重练
- **学情画像**：用雷达图展示识记、理解、鉴赏、表达四个维度，数据根据错因动态计算

## 如何运行

1. 下载或克隆本项目
2. 双击 `index.html`，即可在浏览器中直接打开

无需安装任何依赖。

## 项目结构

- `index.html` —— 页面骨架
- `style.css` —— 全局样式
- `main.js` —— 全部交互逻辑与题库数据

## 说明

- 目前题库以《登高》为完整样板，其他篇目陆续补充
- 问答逻辑使用预设脚本演示，后续可接入大模型 API 实现真正的 RAG 问答
- 本项目为课程项目 Demo，用于展示产品交互设计
